# KARMEN LOOP

[English](README.md) | 简体中文

我们开发 AI 工作工具，也维护一些能独立使用的小项目。先按你要完成的事选择工具，再查看对应仓库的当前下载、教程和许可证。

[Website](https://karmenloop.com) · [Email](mailto:info@karmenloop.com)

## 记忆与任务

- [karmen-memory](https://github.com/KarmenLoop/karmen-memory) — 在浏览器原型里检查和整理记忆。
- [bot-orchestrator](https://github.com/KarmenLoop/bot-orchestrator) — 用本地任务板记录依赖、交件、证据与审阅。
- [personal-agent-growth](https://github.com/KarmenLoop/personal-agent-growth) — 把任务复盘与交接记录保存在共享私有目录。
- [user-behavior-personalization](https://github.com/KarmenLoop/user-behavior-personalization) — 维护用户可检查、更正的范围化偏好，存储由宿主提供。

## 应用与网站交付

- [app-module-delivery](https://github.com/KarmenLoop/app-module-delivery) — 应用、扩展与模块的计划和验收流程。
- [fullstack-web-delivery](https://github.com/KarmenLoop/fullstack-web-delivery) — 网站交付流程，附可运行的虚构企业示例。

## 小型本地工具

这些 MIT 技能附带 Python 标准库工具，可直接处理你提供的 JSON，无需模型账号。每个项目都有中英文入口和从下载到实际练习的教程。

| 项目 | 用途 |
| --- | --- |
| [api-diagnostics](https://github.com/KarmenLoop/skill-api-diagnostics) | API 诊断 |
| [bug-repro](https://github.com/KarmenLoop/skill-bug-repro) | 问题复现记录 |
| [calendar-slots](https://github.com/KarmenLoop/skill-calendar-slots) | 空闲时段 |
| [daily-brief](https://github.com/KarmenLoop/skill-daily-brief) | 每日安排 |
| [document-diff](https://github.com/KarmenLoop/skill-document-diff) | 文档差异 |
| [file-manifest](https://github.com/KarmenLoop/skill-file-manifest) | 文件清单 |
| [follow-up-tracker](https://github.com/KarmenLoop/skill-follow-up-tracker) | 跟进清单 |
| [inbox-triage](https://github.com/KarmenLoop/skill-inbox-triage) | 收件箱分流 |
| [meeting-actions](https://github.com/KarmenLoop/skill-meeting-actions) | 会议行动项 |
| [memory-ledger](https://github.com/KarmenLoop/skill-memory-ledger) | 记忆台账 |
| [patch-risk-review](https://github.com/KarmenLoop/skill-patch-risk-review) | 补丁风险线索 |
| [project-plan](https://github.com/KarmenLoop/skill-project-plan) | 项目依赖计划 |
| [task-checkpoint](https://github.com/KarmenLoop/skill-task-checkpoint) | 任务恢复检查点 |
| [test-failure-triage](https://github.com/KarmenLoop/skill-test-failure-triage) | 测试失败归类 |

工具处理你提供的记录，不会替你发邮件、预订会议或连接账号。
