# KARMEN LOOP

**Your computer. Your models. Your call.**

We build Koder, an AI workspace for coding and everyday work on your own computer. Bring the model you want to use, review the changes, and decide what happens next.

[Explore Koder](https://karmenloop.com/en/koder.html) · [Get started](https://karmenloop.com/en/tutorial.html) · [Downloads](https://karmenloop.com/en/download.html) · [Contact us](mailto:info@karmenloop.com)

## Meet Koder

Work in the desktop IDE, stay in the terminal with the CLI or TUI, or call Koder from your own code with the SDK. KARMEN LOOP is the kernel underneath: perceive, decide, act, then use the result to take the next step.

- **Choose your model.** Connect a model service you already use, or run a local model. Koder does not include one.
- **Review before you write.** See a file change before accepting it. Commands ask first by default.
- **Keep your workspace local.** Koder runs on your computer. Model requests go directly to the provider you choose, under that provider's terms.

The desktop app is in beta. Check the [download page](https://karmenloop.com/en/download.html) for current builds and availability.
